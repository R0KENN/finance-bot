# 💎 Финансовый бот для Telegram

Личный учёт денег целиком в Telegram: доходы с источниками, расходы по категориям,
распределение денег по копилкам, бюджеты, долги, красивые графики и «Статьи».
Всё управляется инлайн-кнопками, у каждого пользователя свои данные.

## Что умеет

**Записи**
- ➕ Доходы «во всех видах»: зарплата, премия, фриланс, инвестиции, аренда, проценты, продажа вещей,
  кэшбэк, подарки. У каждого дохода есть **источник** (работодатель, клиент, площадка) —
  в статистике видно, что приносит больше. Пассивный доход считается отдельно.
- ➖ Расходы по категориям, с заметкой, датой и счётом. Категории, виды доходов и источники можно
  добавлять, переименовывать и удалять.
- ⚡ **Быстрый ввод одной строкой**: `кофе 250`, `такси 400 вчера`, `+50000 зарплата`, `1500`
  (бот спросит, что это). Категорию угадывает по словам.
- ↩️ Отмена записи в один тап, правка суммы, категории, даты и заметки, удаление, поиск по истории.

**Деньги**
- 👛 Несколько счетов (наличные, карты…), остатки, переводы между счетами, исправление остатка.
- 💱 **Несколько валют.** У каждого счёта своя валюта (₽ $ € ₸ ₴ Br ₾ ₺ ֏ сўм) или криптовалюта (₮ USDT, USDC, ₿ BTC, Ξ ETH): например, доходы падают на счёт
  в долларах, а траты идут со счёта в рублях. Статистика, бюджеты, копилки и долги считаются в **основной
  валюте**; каждая операция пересчитывается по курсу **на день записи**, поэтому прошлая статистика не
  «плывёт» при изменении курса. Курсы обычных валют берутся у ЦБ РФ, криптовалют — у CoinGecko (запасной источник Coinbase); при
  необходимости задаются вручную.
  Обмен валюты — это перевод между счетами: вводишь, сколько реально пришло. В быстром вводе можно
  писать валюту: `+500$ зарплата`, `кофе 5 евро` — бот сам выберет (или заведёт) счёт в этой валюте.
  Смена основной валюты пересчитывает всю историю, цели, лимиты и долги по сегодняшнему курсу.
- 🎯 **Копилки и план распределения**: задай процент для каждой копилки — после записи дохода
  одна кнопка «Распределить по плану» раскладывает деньги. Есть готовые шаблоны плана.
  Показывает, на сколько месяцев хватит капитала.
- 🎚 Бюджеты: лимит на категорию и общий. Предупреждает на 80% и при превышении.
- 🔁 Регулярные операции (зарплата, аренда, подписки) — создаются сами, пропущенные дни догоняются.
- 🤝 Долги: кто должен мне и кому должен я, срок, частичные погашения, напоминание в день срока.

**Хомяк** 🐹 — талисман бота. К важным событиям он присылает картинку с короткой репликой:
запись дохода (контракт — за зарплату, король на золоте — за пассивный доход, красная дорожка и вертолёт — за остальное),
траты на кафе, путешествия, транспорт и развлечения, превышение лимита бюджета, распределение денег по плану (весы),
достигнутая цель, закрытый долг, недельный дайджест. Подряд одна и та же картинка не повторяется.
Выключается в «Настройки → Хомяк». Картинки лежат в `finbot/assets/hamster/` — их можно заменить своими
(11 файлов `.jpg` 1024×1024, имена см. в `finbot/services/mascot.py`).

**Аналитика**
- 📊 Сводка за день, неделю, месяц, год или всё время; листание по месяцам; сравнение с прошлым периодом;
  норма сбережений, средний расход в день, прогноз расходов до конца месяца, короткие выводы.
- Графики: расходы по категориям, доходы по источникам, доходы/расходы по месяцам,
  расходы по дням нарастающим итогом (с линией лимита), динамика капитала, прогресс копилок.
- 📬 Недельный дайджест, ⏰ вечернее напоминание записать траты (по желанию).

**Статьи (Telegram Rich Messages, Bot API 10.1)**
- ✍️ Пиши статьи прямо в боте и читай их в красивом формате Telegram — с заголовками, списками,
  цитатами, разделителями и **таблицами**.
- 📥 Перешли боту любую статью из Telegram — он сохранит её в твои «Статьи».
- 📊 «Отчёт за месяц» собирает статью-отчёт с таблицами: сводка, расходы, доходы, копилки.
- Если Telegram не принял Rich Message, статья приходит обычным сообщением — ничего не теряется.
  Проверить, работают ли статьи у вашего бота: команда `/richtest`.

Разметка статьи:

```
# Заголовок        секция
- пункт            список            1. пункт   нумерованный список
> цитата           цитата
---                разделитель
| Статья | Сумма |   таблица (строки подряд, первая — шапка)
обычный текст — абзацы, пустая строка разделяет
```

**Прочее**: 📤 экспорт всех операций в CSV (открывается в Excel), валюта и часовой пояс у каждого свои,
🗑 удаление всех своих данных одной кнопкой.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), скопируй токен.
2. Windows: запусти `run.bat` — он создаст окружение, поставит зависимости и откроет `.env`.
   Впиши `BOT_TOKEN` и запусти `run.bat` ещё раз.

   Вручную:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
   pip install -r requirements.txt
   copy .env.example .env          # впиши BOT_TOKEN
   python main.py
   ```
3. Напиши боту `/start`.

### Настройки (`.env`)

| Переменная | Что делает |
| --- | --- |
| `BOT_TOKEN` | токен бота (обязательно) |
| `DB_PATH` | путь к базе, по умолчанию `data/finbot.db` |
| `TIMEZONE` | часовой пояс по умолчанию для новых пользователей |
| `ALLOWED_USERS` | список Telegram id, которым можно пользоваться ботом; пусто — всем |
| `RICH_MESSAGES` | `off` — всегда слать статьи обычным текстом |

## Развёртывание на сервере (Linux, systemd)

Папка `deploy/`: `setup.sh` — установка службы (окружение, зависимости, проверка, systemd),
`finbot.service` — шаблон службы, `backup.sh` — резервная копия базы. Порядок действий:

```bash
cd ~/finance-bot            # папка бота на сервере
cp .env.example .env && nano .env     # BOT_TOKEN и ALLOWED_USERS
bash deploy/setup.sh
```

Дальше: `journalctl -u finbot -f` — журнал, `sudo systemctl restart finbot` — перезапуск.
Обновление: забрать новый код, снова `bash deploy/setup.sh` (база и `.env` не затрагиваются, схема базы
обновляется сама). Копии базы шлёт сам бот (см. «Бэкап» ниже).

## Валюты и курсы

- Основная валюта и курсы: «Настройки → Валюты и курсы». Там же можно обновить курсы, задать **свой курс**
  для валюты (он главнее автоматического) или вернуться к автоматическому.
- **Криптовалюты** хранятся с точностью до 8 знаков (BTC, ETH: `0,00015`), USDT и USDC — до 2 знаков. Сумма
  никогда не округляется молча: если знаков больше, чем бывает у валюты, бот скажет об этом. В быстром вводе
  можно писать `+0,002 btc фриланс`, `20 usdt обед`, `0,5 eth`. Основной валютой может быть только обычная
  (у крипты нет копеек для бюджетов, копилок и долгов), а счета в крипте вести можно.
- Автоматические курсы обновляются раз в час. Если сеть недоступна, работают последние
  сохранённые курсы; а если курса нет совсем, бот попросит ввести его вручную.
- Копилки, бюджеты и долги ведутся в основной валюте. Регулярные операции — в валюте своего счёта.
- Старая база (без валют) обновляется сама при первом запуске: все счета получают валюту пользователя.

## Данные пользователей

Все таблицы хранят `user_id`, каждый запрос фильтруется по нему, а при записи проверяется, что счёт,
категория, источник и копилка принадлежат этому же пользователю. Подделка чужих `callback_data` ничего
не даёт — это покрыто тестами. Кнопка «Удалить мои данные» стирает всё каскадно.
Деньги хранятся целыми числами в копейках — без ошибок округления.

**Бэкап.** Впиши свой Telegram id в `ADMIN_ID` в `.env` — и раз в сутки (после `BACKUP_HOUR`, по умолчанию 4 утра)
бот пришлёт тебе в личку сжатую копию базы, а на диске сервера копий не останется. Написать боту `/start` нужно
один раз, иначе Telegram не даст ему писать первым. Команда `/backup` присылает копию сразу (только админу).
Распаковать: `gunzip finbot-2026-10-01.db.gz`, получится готовый `finbot.db`. Копия содержит данные всех
пользователей бота, поэтому храни её так же бережно, как саму базу. Вручную: скопировать `data/finbot.db`
(при запущенном боте вместе с файлами `-wal` и `-shm`) или запустить `bash deploy/backup.sh`.

## Устройство

```
main.py                 запуск, polling, планировщик
finbot/
  app.py                сборка диспетчера, обработчик ошибок
  config.py  db.py  schema.py  defaults.py  states.py  middlewares.py
  repos/                работа с данными: по файлу на область (транзакции, копилки, бюджеты, долги…)
  services/             логика без Telegram: деньги, даты, разбор быстрого ввода, статистика,
                        графики, разметка статей, Rich Message, отчёты, экспорт, оповещения
  ui/                   каркас интерфейса: кнопки, смена экранов (текст ↔ фото), диалоги
  handlers/             экраны и диалоги: по файлу на раздел
  scheduler.py          регулярные операции, напоминания, дайджест
tests/                  тесты ядра и сквозные сценарии диалогов
```

## Тесты

Сквозные тесты прогоняют живые диалоги через поддельный Telegram — без сети и токена.
Заодно проверяют, что ни одно сообщение не нарушает лимиты Telegram (64 байта в `callback_data`,
4096 символов текста, 1024 в подписи к фото) и что весь HTML валиден.

```bash
python -m unittest discover -s tests -t .
```
